# THE GEEK HARSH — thegeekharsh.in

Single-page editorial personal site for Harsh Sinha. React 18 + Vite + TypeScript + Tailwind + Framer Motion, statically pre-rendered at build time.

## Setup

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # typecheck + client build + SSR build + static prerender -> dist/
npm run preview   # serve dist/ at http://localhost:4173
npm run lint
npm run format
```

Requires Node 18+. A `.npmrc` sets `legacy-peer-deps=true` (needed only for an ESLint plugin peer range).

## Where to edit content

All copy, links, dates and the paper URL live in **`src/content/site.ts`**.

- `PAPER_URL` — currently the Routledge book page. **TODO:** replace with the chapter DOI.
- `site.now.lastUpdated` — the "Last updated" value.
- `posts` — an empty typed array. Nothing is rendered until you add entries (`slug`, `title`, `date`, `summary`, optional `href`). It can later be fed from JSON or MDX with no layout change.

Design tokens are in `tailwind.config.ts` (colors, fluid type sizes, radius) and `src/index.css`.

## Swapping photos

1. Put full-size JPGs in `public/images/` named exactly:
   - `harsh-portrait.jpg` (portrait, 4:5, e.g. 1200×1500)
   - `harsh-candid.jpg` (landscape 3:2, e.g. 1600×1067)
2. Run `npm run images` (also runs automatically on `npm run build`). It writes `-480/-800/-1200` AVIF and WebP variants next to the JPG.
3. Until a JPG exists the site shows a neutral placeholder block. If you change the aspect ratio, update `width`/`height` in `site.hero.portrait` / `site.about.photo`.

Favicons and the placeholder OG image are generated by `npm run icons` (typographic TGH). Replace `public/og-image.png` (1200×630) with a real design when ready.

## Pre-rendering (why a custom script)

`vite-react-ssg` is built around react-router and its own head manager. This site is a single page and the brief asks for `react-helmet-async`, so the build uses a small equivalent pipeline instead:

1. `vite build` produces the client bundle.
2. `vite build --ssr src/entry-server.tsx` produces a Node-renderable module.
3. `scripts/prerender.mjs` renders the app with `renderToString`, injects the HTML and Helmet tags (`<title>`, meta, canonical, OG/Twitter) into `dist/index.html`, and preloads the critical fonts.
4. The client then hydrates the existing markup.

Crawlers and no-JS clients get complete HTML. Scroll-reveal elements are forced visible under `<noscript>`.

## Deploy

**Vercel**: import the repo, framework "Vite", build `npm run build`, output `dist`. Then Settings → Domains → add `thegeekharsh.in` and `www.thegeekharsh.in` and set the DNS records Vercel shows (A `76.76.21.21` for apex, CNAME `cname.vercel-dns.com` for www).

**Netlify**: build `npm run build`, publish `dist`. Then Domain management → add custom domain `thegeekharsh.in` and point DNS to Netlify (the DNS records it shows).

Both issue HTTPS certificates automatically. There are no client-side routes, so no SPA rewrite is needed.
